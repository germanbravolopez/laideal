# Progress Tracker — La Ideal

**Rule**: Track only what is actionable now. The active sections are:
- **Blocking Issues** — must-fix items before merging the current branch and cutting a release. Items move out of here once resolved (into [`completed_milestones.md`](completed_milestones.md)).
- **Open Non-Blocking Issues** — known backlog that does not gate the release but is still worth doing.
- **Backlog (deferred — low value / not currently planned)** — items consciously parked because the effort outweighs the value (or they depend on an external trigger). Not "open work": revisit only if the trade-off changes. Keeps the Open list a real to-do list.

Add new entries at the **top** of the relevant section. Do not keep an "In Progress" list — work in progress lives in the branch and in Blocking Issues if it gates the release.

## Current Status — October 2026

**Active branch**: `develop`

**Latest release**: [10.11](https://github.com/germanbravolopez/laideal/releases/tag/10.11) — shop fixes and an accounting audit aid. **(1)** Recogida de Prendas `Importe total` no longer counts voided garments: a garment voided in place takes the void date as `fecha_pago`, so Pago-date searches were adding it (ticket 31045). The sum now skips `ANULADA` / `RECTIFICADA` rows through the tested `sql_lite::garmentExcludedFromTotals`, built from the same excluded-estado list as the Contabilidad totals. Unpaid rows still count, so a ticket searched by number shows what is owed. **(2)** Contabilidad reports end with a detail annex listing the paid tickets and the gastos rows behind each period's figures. The listings share one SQL predicate with the totals, counts and annual query, so they reconcile by construction. Gastos rows with an unrecognised IVA are flagged rather than silently totalled. **(3)** Configuración → Verifactu has a Mostrar / Ocultar toggle for the masked service key; it changes the display only. Also in this cycle: the AI-agent tooling moved to `.claude/skills/` and gained the `test-engineer`, `verifactu-compliance-auditor` and `guidelines-auditor` subagents plus a `/debugging` skill (no app impact).
