**Rules**:
- Add new entries at the **top** of the current `### Post-<X.Y> development — <Month Year>` section. `X.Y` is the latest *released* version when the work was done (see "Latest release" in the tracker's Current Status). If a release has shipped since the top section was created, start a new section above it. When a release ships, suffix its section header with `(shipped in X.Y)`.
- Format: `- [x] **Title**: what was done, why, key files.` Write fresh prose about the actual change, with the rationale that is not obvious from the diff. Do not paste the original issue text.
